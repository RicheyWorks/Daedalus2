# ytm-island specs: Blender asset batch specs (youtube-master)

Inputs/outputs of the Youtube Master Island asset batches made with ../ytm_polish*.py, ../ytm_hero.py, ../ytm_plaque.py, ../ytm_records.py: `batch1.json` (asset list with sizes), `hero_v1.json`, `plaque_v1.json`, `records_v1.json`, `polish_v2..v5*.json` (per-batch polish specs). Run logs stay out of git (large, regenerable).
