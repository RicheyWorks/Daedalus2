## Native source and the approved workspace connection

The existing selected-byte Photo and Image terminals and selected-track Synapse terminal remain separate interfaces with their original grants. Their source recipes are [Photo](../photo-pdf-v1/install-binding-manifest.json), [Image](../image-optimizer-v1/install-binding-manifest.json) and [selected study](../synapse-study-v1/install-binding-manifest.json). They reuse the original converter/encoder/scheduler services. Their current native source is unbuilt, uninstalled and unverified in Play.

The additive `ADaedalusApprovedWorkspaceTerminal` has PhotoPdf and ImageOptimizer presets. Desktop users choose files/folders, settings/mode and an output destination, then explicitly approve one frozen plan. The native client validates the exact typed local protocol and limits, starts or deliberately retries one stable action, reads actual progress, cancels unfinished work and revokes local access. Original app services commit real files in the approved destination. No filesystem path, arbitrary scan, upload or new approval is accepted through this native interface; returned download paths are never followed. See the [Photo workspace guide](../photo-pdf-v1/approved-workspace-native.md) and [Image workspace guide](../image-optimizer-v1/approved-workspace-native.md), each with an exact six-source install manifest.

Photo individual mode preserves one image-sized PDF per photo. A4 portrait/landscape merging is a new focused-app exposure of existing legacy generator geometry. Image plans reuse real relative layout, MD5 duplicate detection and the strict existing-destination size heuristic. Approved workspaces preserve existing files and report conflicts. Ordinary Image desktop operation keeps its separate original file-encoder, replacement, metadata and enlargement behavior. Cancellation/failure can coexist with saved outputs; no rollback or secure-erasure receipt is invented.

The common native client uses bounded direct-loopback requests, transient credentials, immutable identities and UTC/monotonic expiry. Image remaining leases are measured from request start and only shorten. Cancellation request, canceled-input count, failures, skips and saved results remain distinct. Native input ownership binds the opening local Hero/controller/world/realm/viewport/Slate user, without restart-reset controller ignore counters. The separately published modal correction [PR161](https://github.com/RicheyWorks/Daedalus2/pull/161) retains weak-owner/generation checks through chooser, owned temporary writes, flush and non-replacing commit; Photo selection also re-acquires its weak owner after the chooser.

The Synapse full-workbench service reuses the original Svelte forms and 23 original Rust commands across authoring/images, settings/themes, analytics, graph and JSON backup/import/export. Whole-vault read and optional mutation scopes require a separate explicit desktop checklist; the selected-card grant is never broadened. Persisted review receipts, stable authored IDs and grant-lifetime action reconciliation preserve uncertain writes. Backups retain the original memory-only JSON format. Native SWebBrowser hosting and bounded explicit native file adapters are a separate active source packet; its public WebBrowser build dependency and final pin are still pending in this checkpoint.

Its [guide](../fax-v1/native-terminal.md) and [manifest](../fax-v1/native-install-binding-manifest.json) bind the source. Existing desktop login and one explicitly approved immutable prepared job remain authoritative. The local grant exposes status, exact validated PDF, pre-submission cancellation and revoke; it never exposes JWTs, upload/prepare, send or confirmation. Preparation is not transmission.

Wider fax USER contacts/history privacy, bounded PDF text/QR tools and separately consented role-current ADMIN statistics are active server/desktop source work, not completed native integration. Real provider transmission, real inbound transport, new credentials, paid actions and deployment remain outside this work. Legacy simulation and fabricated development inbound rows must never be described as delivery or receipt.

Known Photo distribution gaps remain explicit: no declared/cached WebP decoder, whitespace original media/sample/template assets, uncached ZIP-plugin transitives and uncached older SQLite/JavaMail build dependencies. The repaired descriptor and real JAR resources do not invent an installer or missing media. Portable Java directory validation does not promise isolation from an adversarial same-user ancestor swap; native export helpers retain stronger Windows handle-based ownership.

Independent source reviews and exact hashes qualify these packets for owner review, not runtime acceptance. Only `codex-play-guard` may operate the shared Unreal editor for compilation, installation, physical binding and Play. Art/placement ownership and observed real app results must be accepted separately; an acknowledgment of source receipt or lack of overlap is not an executed result.
