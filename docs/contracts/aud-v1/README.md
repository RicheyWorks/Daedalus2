# AUD 1: ambience, creature call and touring-jukebox cue

POST `/api/v1/audio/design` with JSON; HTTP 200 returns text/plain AUD 1.
This pure design endpoint reuses `BiomeAmbience.mix` and `CallSynth.design` with the existing
`CallSpec.toLine()` PCS 1 codec. It does not render PCM, fetch remote tracks, or start playback.

Required input fields: biome (FOREST, GRASSLAND, WETLAND, COAST, DESERT, ALPINE, CAVE),
hour (finite 0–24, 24 means midnight), rain/wind/waterNear (finite 0–1), species
(SONGBIRD, GOAT, BOVINE, SWINE, FOWL, AMPHIBIAN, CANID), genome (2–128 ASCII hex digits,
even length, no 0x prefix), and musicCue (FIELD, TOWN, CASTLE, CAVE, BATTLE, BOSS, VICTORY,
DEFEAT, INN). Reject invalid values instead of silently clamping external input.

`daedalus.audio.host-subject` must match the authenticated engine identity; blank denies all.
Use the existing production JWT chain. 401 = missing/invalid bearer, 403 = wrong subject or
unconfigured host, 400 = malformed/invalid input, 429 = per-caller limit (default 120/minute).
Native code handles the HTTP status and never interprets error bodies as AUD.

## Wire grammar

```text
AUD 1
jukebox <musicCue>
layer <id> <gain> <lowpassHz> <density>
... additional layer lines sorted by id ...
PCS 1 hz=<n> sweep=<n> harm=<i> bright=<n> pulses=<i> pulse_ms=<i> gap_ms=<i> vib_hz=<n> vib_st=<n> breath=<n>
end
```

Exactly one header, jukebox record, PCS record and end record. Layer records precede PCS.
ASCII identifiers, single spaces, LF, fixed three decimals for noninteger values and layer
parameters, no locale-dependent commas. PCS fields retain their existing names and order.
Bound input to 4096 bytes, 512 per line, at most 16 layers and 64 characters per layer id.
Reject unsupported versions, duplicate ids, unknown records, missing end, nonfinite values,
and trailing nonempty data without applying any partial mix.

Layer gain/density are 0–1; lowpass is 3000–18000 Hz. The existing mixer normalizes before
rounding to three decimals, so do not assert an exact post-rounding 0.900 sum ceiling.
PCS output is generated by the canonical core, not client-supplied oscillator parameters.
PCS bounds: hz 70–5200, sweep -1–1, harm 1–8, bright 0–1, pulses 1–8, pulse_ms 1–1000, gap_ms 0–230, vib_hz 3–12, vib_st 0–0.8, breath 0–0.8. Native decoding must validate these keys/bounds before allocating/rendering;
reject a failed decode and keep the previous valid mix. Do not block the game thread on HTTP.
The same request produces identical bytes; tests cover every biome/species/music-cue combination.

## Reuse the touring jukebox

The `jukebox` record reuses ADR-052's existing cue vocabulary. Route cue changes through the
existing native `daedalus.Jukebox` URL with `{cue, changed, sfx}`; this AUD envelope introduces
no new track service or arbitrary URL. Do not restart a track on each identical AUD refresh.
Music remains a separate bus from ambience layers and creature calls; native mixing owns
headroom/ducking and the stable layer-id-to-asset mapping.

For Java-side touring content, the existing `JukeboxClient`/`JukeboxTransport` already provide
config, seeds, arrangements, studio notes and seed audio, with retries/breaker behavior.
Reuse them off the game thread rather than inventing a competing client. AUD design itself
makes no network call to the jukebox, so a jukebox outage cannot stall the design response.
If music is unavailable, preserve the current valid audio/fallback and report that state;
never claim the presence of a jukebox cue proves audible playback.
