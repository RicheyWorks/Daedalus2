## Small native checks

Run one workflow per bounded unsaved check, through the existing sole operator.
Use the current accepted184 preservation boundary and existing play guard. Do not
reuse old140-only rollback or admission scripts. Do not restart the editor or
install a different DLL for this packet.

1. Start one fresh synthetic companion fixture, or explicitly approve only the
   generated input/output directories in the existing desktop application.
2. Open the matching object near the local Hero, paste its fresh private link and

3. Perform one real action through the panel. A dispatched request or busy

   native UI, file-dialog, saved-file and gameplay outcomes as separate facts.

### Selected photo/PDF

Choose the generated red/blue PNG and JPEG through **Choose photos**; canceling
that chooser must submit nothing. **Convert photos**, then **Refresh** until the
actual job succeeds. Use **Export PDF 1/2** to choose new test-owned filenames.
Expect two single-page image-sized PDFs, with the original input dimensions.
PDFBox page/image-box/rendered-pixel checks provide structural/content evidence;
the native header/end-marker check alone does not.

Try exporting to an existing sentinel file and canceling a save chooser. Both
must preserve the sentinel and leave no committed partial output. **Cancel /
delete job** clears only the owned job; already exported files remain. A retry of
an uncertain conversion retains the same action and bytes.

### Approved photo/image workspace

The desktop freezes the input selection, settings and explicit destination.
**Pair approved workspace**, then **Start / retry same approved action** and
**Refresh actual progress**. Verify saved/optimized, failed, skipped and conflict
counts separately against actual files. Repeating the same action must not
produce another job or overwrite an existing destination.

Test a fresh canceled plan separately. **Cancel unfinished work** and **Revoke
local access** cannot recall committed files. A failed/canceled plan requires a
new explicit approval. Persisted output files are separate from durable job
history; the latter is not claimed by these transient services.

Photo image-sized mode retains the original one-PDF-per-photo behavior. Merged
A4 portrait/landscape is an explicitly added exposure of existing legacy layout
geometry and must be reported as an enhancement.

### Synapse

Use a fresh evidence-only vault. Exercise the original UI to create/edit a
synthetic memory, study it, change a setting and export a JSON backup. Restart
the service normally against that exact test vault and verify the persisted
memory/setting/review receipt and backup contents. Backups retain the original
memory-only format; do not assume they include settings or history. Repeat a
review with the same action to check receipt recovery without a second schedule
change. Browser automation against the local original UI does not establish
Unreal CEF binding or the native no-replace JSON save dialog.

### Fax

Do not enter/configure credentials, attach a provider, send a fax, access private
documents or start a production backend for acceptance. Existing preparation and
owner-scoped backend tests can run with synthetic test fixtures. A rendered
workbench backed by mock access demonstrates page/bridge behavior only; it does
not demonstrate real account/history persistence or provider delivery. Keep the
full backend/paired native workflow pending until an existing authorized local
fixture is available. Legacy simulated sent labels are not transmission proof.
