# Budget Trend Ledger (G517, DiskSaver Island, quest q_budget_ledger)

Post-contest disk/memory tooling (buffffff lane, 2026-10-29). Source only, no editor, no assets.

## What it does
`tools/streaming/budget_ledger.py` keeps a history of the streaming budget. Each World Census
run (`census.json`, or an already-made G206 `census_budget.py` report) is priced with the G206
model (40000 KiB RAM / 32768 KiB disk, amber at 900 permille) and appended as one JSON line to
a ledger. Inputs are read-only; the ledger is append-only and refuses a duplicate run id.

Records carry no clock time: `at` is whatever `--at` passes in (or null), so bytes are stable.

## Commands
```
python tools/streaming/budget_ledger.py record census.json --ledger L.jsonl --run census-004 --at 2026-10-29
python tools/streaming/budget_ledger.py diff  --ledger L.jsonl [--from ID] [--to ID] [--json] [--fail-on-worse]
python tools/streaming/budget_ledger.py trend --ledger L.jsonl [--last 5] [--json] [--fail-on-worse]
```
- `diff` (default: last two runs): per-world RAM/disk deltas and findings `beacon_worse`,
  `beacon_better`, `newly_over`, `back_under`, `appeared`, `appeared_hot`, `dropped`.
  A world is *over* when it has a red island or cannot hold every island resident.
  Verdict `worse` when any of `beacon_worse`, `newly_over`, `appeared_hot`; else `steady`.
- `trend`: per world over the last N runs, `growing` / `shrinking` / `flat` by net RAM change;
  tally `rising` if any world grows, else `ebbing` if any shrinks, else `steady`.
- Exit 0 ok; 1 only with `--fail-on-worse` (diff worse, or trend rising); 2 refusal.

## Daedalus hook
`data/islands/disk-saver/budget-ledger-v1.json`: Tally Clerk Wren cuts one notch per world into
the tide post on the quay for every census (`worlds[].ram_kib` from `trend`). The post's slope
is the `tally` (`steady`/`rising`/`ebbing`) and picks Wren's line; a `worse` diff carves the
notch red. Where Beacon Watch (G505) gates one change, the tide post shows the history.

## Example
`data/islands/disk-saver/budget-ledger-example.jsonl`: run 1 is the real World Census fixtures
pipeline; runs 2-3 add drift (beta goes amber then drops out, gamma appears, alpha slot 2 goes red).
Tests pin the file to the regenerated bytes.
