SHARDRING RESONANCE

Set each Prism Shard in an empty facet of the sphere ring; 3 or more of one hue in a row resonate and clear. Do not let the ring fill. Click a facet, or use Left/Right to pick and Enter/Space to set. Keys 1-9 and 0 set facets 1-10 directly; R restarts. Controller: D-pad or left stick picks, A sets, Start restarts.
