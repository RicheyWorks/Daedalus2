# `_migration/` is an archive, not live code

This directory holds the 2026 multi-module split playbook and earlier
portfolio / audit drops. **Nothing here is compiled, tested, or served.**

Search hits a second `PluginManager`, old `MazeController`s, and packages
that no longer exist in the reactor. Those files are leftovers. The live
tree is the five `daedalus-*` modules at the repo root.

Git history still has every byte. Do not copy from here into the reactor
without treating it as a foreign snapshot.
